# Notes for agents

Run everything through uv (`uv sync`, `uv run …`), and read `docs/architecture.md` before designing anything: it is the plan, and its ADRs record decisions already made. Before a final commit, make sure `uv run ruff check .`, `uv run ruff format --check .`, `uv run ty check` and `uv run pytest` (which also runs the numpydoc docstring gate) pass, and fix what they flag rather than silencing it. Public code gets type annotations and numpydoc docstrings that state units and tensor shapes, and an API change updates the tutorial and example notebooks it touches in the same commit. A change to the fields of a registered class or a core container or carrier bumps its `schema_version` and regenerates `tests/snapshots/schemas.json` (`GRADIX_UPDATE_SNAPSHOTS=1 uv run pytest tests/test_schema_snapshot.py`). Leave `docs/background/` as it is, because it is provenance. Otherwise move fast: experiment, run code and refactor freely, since these checks are for the final commit, not for every step.
